    The task in PandemicEnv

    Counties near Dallas County, Texas, in the COVID-19 wave of spring and summer 2021, simulated with the county model of Pei, Kandula and Shaman. A variant 1.8 times as transmissible enters through the airport counties. Each day a design moves mobile testing teams (200 tests a day each) along commuting links and raises 14-day local alerts from a fixed budget. The score is the number of infections the variant causes by day 90, against no action on the same seed.

    The state coordinator reads every county's reports and gives every order. NatureSwarm's counties decide for themselves, share findings with commuting partners, and raise an alert only on first-hand evidence. The detection program uses fixed rules and no language model. The oracle sees true infections; it bounds what any design could do.

    Each panel shows its design's variant infections so far at the top right; the chart under each map draws the same count over the 90 days against no action on the same seed (dashed).
